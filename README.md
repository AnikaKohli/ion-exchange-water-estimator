# Water Quality & Hardness Estimator (Mini Project)
### Built for Ion Exchange (India) Ltd Internship Showcase

A clean, beginner-friendly, and interactive web tool built with **HTML5, CSS3, and JavaScript**. It helps domestic and industrial users estimate their water hardness and recommends the right **INDION®** water softeners and resins.

---

## 🌟 Features Included

1. **Interactive Inputs**:
   - **Water Source**: Borewell / Groundwater, Municipal Tap, Tanker, River.
   - **TDS (Total Dissolved Solids)** in ppm with real-time slider (50 to 2000 ppm).
   - **pH Level** slider (4.0 to 10.0) with automatic *Acidic / Neutral / Alkaline* detection.
   - **Daily Water Consumption** in Liters (200 to 20,000 L/day).

2. **Smart Water Hardness Categorization**:
   - 🟢 **Soft Water** (0–60 ppm): Safe, no limescale.
   - 🔵 **Slightly Hard Water** (61–120 ppm): Minor scaling over time.
   - 🟡 **Hard Water** (121–180 ppm): Scale on geysers, showers & taps.
   - 🔴 **Very Hard Water** (181+ ppm): Severe scaling, requires high-capacity softener.

3. **Automatic INDION® Product Recommendations**:
   - Dynamic recommendation message (e.g., *"Based on your TDS of 450 ppm and daily usage of 1,000 Liters, we recommend the INDION Water Softener Series."*).
   - Resin calculation: estimates liters of **INDION® 225 Na** cation resin required.

4. **1-Click Export & Download**:
   - **Download Report (.txt)**: Generates a clean text file summary.
   - **Print / Save PDF**: Print-ready format.

---

## 🚀 How to Run

Simply open `index.html` in any web browser (Chrome, Edge, Safari, Firefox). No setup or server required!
